# Codex

Codex (CLI, desktop app and IDE extension) gets every feature except clickable buttons and side panes, through a Codex plugin.

> **Unconfirmed details.** OpenAI's documentation could not be reached while this was written. The plugin format below comes from third-party write-ups that disagree on version numbers. Milestone M0 confirms each item against OpenAI's official docs and updates this page; see [platform-facts.md](../platform-facts.md).

## How it plugs in

| Feature | Codex form |
|---|---|
| Custom buttons | `submit`/`fill` buttons become slash commands generated by `ccb sync codex`; other types map to skills |
| Regenerate Prompt | `regenerate-prompt` skill |
| Continue | `continue` skill |
| Notes | `notes` skill, using `ccb-mcp` note tools on the same `notes/*.md` files |
| Prompt Bank | `prompt-bank` skill + `ccb-mcp` tools; each prompt also generated as a slash command |
| Google Drive sync | `ccb-mcp`, the same server Claude Code uses |

## Plugin files (expected layout, confirm in M0)

```
plugins/codex/
├── .codex-plugin/plugin.json           manifest: name, version, description, bundled skills, MCP server
└── skills/
    ├── continue/SKILL.md
    ├── regenerate-prompt/SKILL.md
    ├── prompt-bank/SKILL.md
    └── notes/SKILL.md
```

Each `SKILL.md` has a front-matter `name` and `description` (what triggers it) and step-by-step instructions that call the `ccb-mcp` tools.

## MCP tools exposed by `ccb-mcp`

| Tool | Purpose |
|---|---|
| `bank.search` | Search prompts by text, category, tag, favourite |
| `bank.get` | Get one prompt, optionally with variables expanded |
| `bank.save` | Create or update a prompt |
| `bank.delete` | Delete (tombstone) a prompt |
| `bank.list_categories` | List categories with counts |
| `variables.list` / `variables.set` | Read and change prompt variables |
| `buttons.list` | List buttons and their actions |
| `notes.list` / `notes.read` / `notes.append` / `notes.write` | Notes |
| `sync.now` / `sync.status` | Trigger and inspect Drive sync |
| `refine.instructions` | Return the Regenerate instructions, so the client model can rewrite text itself |

The same tools serve Claude Code and the Claude Desktop Chat tab.

## Generated slash commands

`ccb sync codex` writes one command file per prompt and per `submit`/`fill` button, in the location Codex reads custom commands from (third-party sources mention `~/.codex/prompts/<name>.md`, invoked as `/prompts:<name>`, with `$ARGUMENTS` placeholders; confirm in M0, including whether this feature has been superseded by skills). `{{?ask}}` variables become command arguments. Generated files carry a header marking them as generated so `ccb` only ever rewrites its own files.

## Hooks

Not used in v1 (default decision; see [decisions.md](../decisions.md)). Codex hooks were reported as behind a feature flag in 2026. A later version may use a prompt-submit hook to expand `{{variables}}` typed directly into the Codex prompt.

## Install (planned, command confirmed in M0)

```bash
codex plugins install bahattab/Claude-Codex-Custom-Buttons
npx ccb login
npx ccb sync codex
```
